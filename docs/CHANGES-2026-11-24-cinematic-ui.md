# 2026-11-24 — 深黑配色、交错切页与 3D 卡片

## 视觉

- 深色主题整体再压暗一档：窗口纸面、面板、字段、玻璃层、雾色和 3D 房间背景都改为更接近纯黑的暖黑；金色只保留在强调按钮、边缘反光和关键文字上。
- 右栏主卡、底栏、下载卡、Mod 卡、设置项和弹窗增加更深的投影、内侧顶边高光与底部阴影，让卡片在暗场中有真实的厚度。
- 卡片悬停时不仅上浮，还会随指针产生 3D 倾斜；指针离开时以阻尼回正。主要玻璃面板、卡片和配置项均接入同一套倾斜参数，避免只有一处“立体”。
- 动态渐变描边保留，并在悬停/聚焦时提亮和加速流动。
- 启动器加载完成后的整页入场改为更明显、更慢的分向淡入：品牌、导航、页签、主卡、计数器、方向控制、底栏从各自方向先后进入。

## 切页

- **移除所有切页高斯模糊**，切换过程中不再模糊画面或遮挡阅读。
- 旧页与新页改为交叉淡化和轻微纵深位移；页面顶层元素每 100ms 错开进入，子项再以约 38–45ms 的短间隔跟进。
- 元素从下方 30px、轻微缩小并带 `rotateX` 的角度弹入，回弹幅度比上一版更明显，但不会影响点击和布局。
- 减动态效果时所有位移、倾斜和交错动画立即停止，内容保持清晰可见。

## 字体

- 全局正文、导航、按钮、表单和列表改用随包分发的 **LXGW WenKai / 霞鹜文楷**，让界面拥有图片里那种手写书卷感，同时保持正文可读。
- 中文大标题、主卡标题和启动/关于页的标题使用 **Ma Shan Zheng / 马善政毛笔楷书**；Latin 品牌 VITRINE 仍保留 Source Serif 4，不改变大小写。
- 3D 卡面与标签画布也改用 LXGW WenKai，避免 DOM 与 Three.js 里出现两套字体。三个字体均有本地 OFL 许可文件，并列入 NOTICE。

## 其他

- 主界面底栏移除了“核心已连接”和“下载镜像源/线程分段”两枚状态展示，只保留右侧的关于入口。
- 首页不再加载或显示 Minecraft 照片背景；原 Three.js 档案架、暗场和金色反射保持不变。
