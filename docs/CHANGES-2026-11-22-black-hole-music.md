## 1. 这一版做成了什么

数据流一眼看：

```
网易云网页接口 ──weapi──▶ core/src/music（netease → service）──12 个 music.* RPC──▶ src/app/music（music-view / player）
player ──音频──▶ 喇叭
player ──频谱（Web Audio 分析器；读不到时用"编出来的律动"）──▶ spectrum.ts ──▶ 档案板 / 卡片 / 歌词字母 一起跳
player 的歌词与进度 ──▶ lyrics-feed ──▶ space/lyrics3d.ts（3D 歌词）；进度 ──▶ 黑洞光子环上的进度弧
```

| 您的要求 | 现在的做法 |
|---|---|
| 内置网易云音乐播放器 | 核心里**原创**的网页版接口客户端（`core/src/music/`）：二维码登录、搜索、推荐歌单、榜单、每日推荐、我的歌单、歌词、取播放地址；12 个 `music.*` RPC（RPC 总数 89 → 101）。界面里有原创播放器（队列 + 一个 audio 元素）。设置里新增：音质、音量、播放模式（顺序 / 循环 / 单曲 / 随机）、"游戏运行时暂停音乐"；默认是极高音质（`exhigh`，服务端给不了会降级）、音量 0.6、列表循环、游戏运行时暂停开。 |
| 登录点击才弹出登录 UI | 推荐列表的第一张档案是"扫码登录"，**点它**才去要二维码，二维码直接印在这张 3D 档案的正面（二维码编码器 `qr.ts` 是我自己写的，没用库）；扫码、确认后变成昵称。需要登录的来源（每日推荐、我的歌单）未登录时会提示"点第一张'扫码登录'档案"。 |
| 音乐页：照"黑洞 / 吸积盘"那张图（gravity-journey）设计，保留莫比乌斯环 | 一个黑洞：阴影 + 光子环 + 吸积盘。每个像素按预先算好的 Schwarzschild 光线偏折表查出光的去向（`geodesic.ts`），所以引力透镜把盘的背面"抬"到阴影上方、光子环的形状都是对的；盘带多普勒增亮（朝向我们的一侧更亮）和开普勒剪切（内圈转得更快）。这是"物理上合理的艺术化"，**不是科研级渲染**。**碎片就是首页 ∞ 环 / 下载行里的同一批 360 片板**：进入音乐页时它们从各自的位置飞向黑洞周围，离开时飞回。 |
| 所有档案分散在宇宙空间，旁边信息排列整齐简洁 | 档案板在黑洞周围的空间里漂浮、缓慢翻滚；左侧是"正在播放"信息板（封面、歌名、频谱条、进度、播放列表），底部是播放胶囊，四角有星图风格的公式框（`R_s = 2GM/c²`、`M = 6.5×10⁹ M☉` 等）。**公式框里除了 T（= 这首歌的时长）都是装饰性标注，角落的坐标也是装饰文字，不是实时物理量。** |
| 鼠标水波纹 | 您后来说"不做鼠标水波"，所以**鼠标不再触发水波**。水波的物理代码（`space/ripples.ts`）还留在里面但不会被触发。 |
| 3D 歌词，不要 UI 固定歌词，动效歌词随音乐跳动 | `space/lyrics3d.ts`：歌词画在场景里（HTML 里没有歌词面板）。当前行大而亮地站在黑洞前方中间；**每个字母跟着它所在频段跳**（左边字母听低音，右边听高音）；唱到哪个字，就从白变金；前后各 2～3 行像鼓面一样向远处弯曲、变暗变糊（景深）；有翻译行和歌名卡；纯音乐显示歌名和"· 纯音乐"。没有时间轴的歌词会按歌曲时长均匀铺开。 |
| 鼠标到特定位置才显示卡牌（最好是右边），歌词在中间，卡片伴随镜头移动 | 卡片默认隐藏。鼠标移进画面**最右侧约 1/4**，卡片沿一条屏幕弧线从右边抽出，镜头同时平移、倾斜、拉近让出位置；歌词始终在中间。鼠标离开约 1.7 秒后收回。 |
| 3D 可交互 | 旋转、缩放、点黑洞播放/暂停、拖光子环跳转进度，见第 2 节。 |
| 电影级材质 | `cinema.ts`：泛光 → 镜头色散 / 暗角 / 颗粒 / 变形宽银幕式拉丝光（带抖动采样，避免条纹）→ ACES 色调映射。深空里**不做景深**（相当于长焦镜头，全部清晰；糊开会把碎片和星星融成软圆盘），景深随世界淡出。最低画质档自动关掉这些后处理，拉丝光只在渲染比例 100% 的档位开。 |
| 档案随音乐频率跳动 | `spectrum.ts` 把音乐切成频段；每片板、每张卡片听自己所在位置的频段（焦点处听低音，环的远端听高音）：升起、拉伸、被主题色点亮（调节旋钮是 `fin-band.ts` 里的 `BOUNCE`）；正在读的那张卡只允许跳一点点。读不到真实频谱时（浏览器不让页面读取跨域音频）退回一段"编出来的律动"，形状相同。Electron 里我给网易云音频域名加了 CORS 响应头，应当能读到真实频谱（**没在真机验证**）。 |
| 配置档案大小 | 设置里 `ui.cardSize`（小 / 中 / 大，默认中），顶部 3D 控制板上也有一块三格的切换板；环、被读的卡片、下载行一起缩放（弹簧过渡）。 |
| 尽量减少按键，都在 three.js 里交互 | 顶部视图标签、档案大小切换、音乐页的来源 / 搜索 / 返回，都是 3D 场景里的"索引片"（`control-rail.ts`，单独一层透明 canvas，不会被景深和环境光遮蔽弄糊）。非音乐页的右上角有个会转的 3D 音乐碟。**仍然是 HTML 的**：音乐页左侧信息板、底部播放胶囊（上一首 / 播放 / 下一首 / 模式 / 进度 / 音量）、右边缘的"档案 ‹"提示、星图公式框。胶囊保留是因为小控件在 3D 里不好点；点黑洞、拖光子环是同样功能的 3D 版本。 |
| 每个页面都是莫比乌斯环重组来的 | 沿用 11-08 的重组（环 → 行）；音乐页在这个基础上让同一批板继续飞向黑洞；离开时从音乐页回到下载行或首页环。`download.resume(kind)` 负责"从音乐页回到某个下载分类"的衔接。 |
| 新气质：人类探索未知 | 默认主题改为**深空（暗色）+ 金色强调色**，新图标（两个环交成 ∞，一环白一环金，深色底），新开屏（两个环自己画出来并扣在一起，交点像吸积盘的第一缕光一闪）。设置里"界面配色"选项顺序改成"深空 / 亮色 / 跟随系统"。默认暗色只对新安装、或没保存过这一项的设置生效，已经保存的配色不会被改。 |

## 2. 怎么操作（音乐页）

| 操作 | 效果 |
|---|---|
| 鼠标移到画面最右侧 | 卡片从右边抽出，镜头让开；离开约 1.7 秒后收回 |
| 鼠标滚轮 | 选择上一张 / 下一张档案（同时唤出卡片） |
| 点黑洞的阴影 | 播放 / 暂停（按下后移动超过 7 px 就算拖动，不触发） |
| 按住光子环（进度轨道）拖动 | 画面实时跟手，**松手才真正跳转** |
| 在空处按住左键拖动 | 旋转视角（翻滚 + 俯仰，带惯性） |
| 右键拖动 / Shift + 左键拖动 | 在卡片、阴影、轨道上也能旋转 |
| Ctrl / ⌘ + 滚轮，触控板双指捏合，触屏双指捏合 | 缩放 |
| 双击空处 | 重置视角 |
| ↑ ↓ ← → | 选择上一张 / 下一张 |
| Enter | 播放选中的歌 / 打开选中的歌单 / 获取登录二维码 |
| 空格 | 播放 / 暂停 |
| `/` 或 Ctrl + K | 搜索 |
| Esc | 在歌单里：返回上一级列表；否则回首页 |

窗口很小的时候会自动省略一部分信息：虚拟宽度不足约 1000 px 时星图公式框不显示，高度不足约 720 px 时播放列表隐藏。

## 5. 性能策略

- **沿用**：窗口失焦 / 最小化 / 游戏运行时暂停或降帧 3D 动画，必要时释放显存，聚焦后恢复（设置里 `ui.whenUnfocused`、`pauseWhenGameRuns`、`releaseGpuWhenGameRuns`）。音乐本身在窗口失焦时**不会**停，只有画面停。
- **新增**：设置 `music.pauseWhenGameRuns`（默认开）——游戏运行时暂停音乐，游戏关闭后继续。
- 黑洞世界的着色器**只在音乐页（以及飞入 / 飞出的过渡中）运行**，其它页面不付这笔费用。
- 电影后处理在最低画质档关闭，拉丝光只在渲染比例 100% 的档位开启；深空里景深关闭（随世界淡出，完全进入后这一遍后处理不再运行）。
- 频谱：能读到真实音频时用 Web Audio 分析器，读不到时用编出来的律动（计算量很小）。
- 小窗口自动省略公式框和播放列表（见第 2 节末尾）。

## 7. 已知问题

1. **歌词主行在吸积盘最亮的一侧（多普勒增亮的一侧）对比度会下降**，字会有点融进背景。旋钮在 `src/space/lyrics3d.ts` 片元着色器里的 `dark = mix(back, halo, vBlur) * 0.55`（调大 → 描边更深）。我试过 0.84，但没来得及验证，所以还原成验证过的 0.55。另一个办法：转动视角让亮侧离开歌词。
